critDim(4) = 112 — and a Coincidence That Isn’t One
Course: dm³ 102  ·  critDim  ·  Source: dm3CriticalityPrinciple_extended.lean

By the same construction as Week 7: axiom nBonacciRingSize_4 : nBonacciRingSize 4 = 56, and lemma critDim_4 : critDim 4 = 112 := by unfold critDim; rw [nBonacciRingSize_4]; norm_num — genuinely sorry-free, again conditional on an externally-sourced axiom, not independently computed in AXLE.

A correction worth restating, not glossing over
An earlier version of this course description noted that the AXLE sorry_inventory.csv audit file happens to have 112 rows, and flagged — correctly — that this is a coincidence, not a structural finding: that file’s row count is a snapshot of distinct file/theorem entries under review (1,041 total sorrys, 1,027 still open as of the last audit cited), not the same kind of object as the fixed arithmetic constant \(\text{{critDim}}(4)=112\). A CSV row count changes as entries are opened or closed; \(\text{{critDim}}(4)\) does not. Matching numbers between a fixed constant and a moving audit count is exactly the kind of pattern worth being suspicious of, and this course caught it before it became a claim. Keep applying that same suspicion to every numeric match you encounter in this material, including the string-theory \(D=26\) match from Week 7.

What is real here: the arithmetic \(2\cdot(56-1)+2=112\) is mechanically verified, exactly like Week 7’s \(2\cdot(13-1)+2=26\). What remains open: independent verification of \(\text{{nBonacciRingSize}}(4)=56\) itself, sourced from the same external “Navrátil” document as Week 7’s \(13\).

This week’s content is grounded in the AXLE/GTCT Lean sources and Book 3 chapters cited above — where a claim rests on an axiom sourced outside this repo, that is stated explicitly rather than presented as independently verified.
