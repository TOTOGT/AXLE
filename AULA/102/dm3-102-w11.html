critDim_monotone — A Genuinely Closed Proof
Course: dm³ 102  ·  Lean Lab  ·  Source: dm3CriticalityPrinciple_extended.lean

Unlike Weeks 7 and 10, this week’s theorem is a genuine derivation, not a one-line arithmetic check: theorem critDim_monotone : ∀ m n : ℕ, 3 < m → m < n → critDim m < critDim n. The proof uses nBonacciRingSize_monotone (itself an axiom: \(\forall m\,n, momega tactic — a decision procedure for linear arithmetic over integers, which can mechanically verify the final inequality once the pieces are in place.

What omega actually buys you here
omega is not doing anything mysterious — given \(\text{{nBonacciRingSize}}(m)<\text{{nBonacciRingSize}}(n)\) and the definition \(\text{{critDim}}(k)=2(\text{{nBonacciRingSize}}(k)-1)+2\), the inequality \(\text{{critDim}}(m)<\text{{critDim}}(n)\) is pure linear arithmetic, and Lean can check that mechanically and completely. The genuine mathematical content is entirely in the monotonicity axiom being assumed — once you have it, the rest is bookkeeping. This is a clean example of a real, valid, sorry-free Lean proof whose actual difficulty lives entirely upstream, in an axiom this course cannot independently verify.

theorem critDim_monotone :
    ∀ m n : ℕ, 3 < m → m < n → critDim m < critDim n := by
  intro m n hm hmn
  have hmono : nBonacciRingSize m < nBonacciRingSize n :=
    nBonacciRingSize_monotone m n hmn
  have hgt : nBonacciRingSize 3 < nBonacciRingSize m :=
    nBonacciRingSize_monotone 3 m hm
  have h13 : nBonacciRingSize 3 = 13 := nBonacciRingSize_3
  have hpos : 1 ≤ nBonacciRingSize m := by omega
  unfold critDim
  omega
